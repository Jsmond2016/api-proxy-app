## 背景与目标

为微信开发者工具提供一个 macOS 桌面代理，在不修改小程序业务代码、构建配置或请求封装的前提下，将指定 HTTP/HTTPS 请求选择性转发到 Apifox Mock。应用只监听 `127.0.0.1`，不自动修改 macOS 全局代理；HTTPS 通过本地 CA 进行 MITM，用户必须显式导入并信任该 CA。

目标闭环为：配置联调项目 -> 连接在线 Apifox 项目 -> 按 Tag 预览并同步接口 -> 在微信开发者工具配置本地代理 -> 按规则 Mock 或透传 -> 查看脱敏请求记录并排查问题。

## 用户与核心流程

目标用户是使用微信开发者工具进行小程序联调的开发者。典型流程如下：

1. 创建或编辑联调项目，填写项目名称、真实源域名、可选路径前缀和本地端口。
2. 在 Apifox 配置弹框中填写在线项目 ID、Mock 前缀、Access Token 和可选 Mock Token，验证连接并选择 Tag。
3. 预览接口差异，确认后替换当前 Profile 的 Apifox 来源接口，同时保留 Custom/Imported 接口。
4. 按需编辑、删除、批量删除或跨 Tab 移动 Mock 接口；可单接口测试、仅调试当前接口或绑定本地预设响应。
5. 应用自动监听活动项目端口，默认全量透传。用户在微信开发者工具中把 HTTP/HTTPS 代理设置为 `127.0.0.1:<port>`。
6. 信任 CA 后打开全局 Mock；命中 host、路径范围、Method 和已启用接口的请求转发到 Apifox，其他请求原样透传。
7. 在请求记录、接入检查和诊断面板中查看命中阶段、目标、响应码、耗时及脱敏错误信息。
8. 关闭应用前将微信开发者工具代理恢复为直连。

## 功能需求与验收标准

| ID | 需求 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| R1 | 联调项目与 Tabs 管理 | 可创建、编辑、删除、切换项目；至少保留一个项目；每个项目独立保存域名、路径前缀、端口、Apifox 配置、规则和本地响应；重启后恢复；新增 Tab 创建弹窗自动预填首个 Tab 的项目配置和 Apifox 连接字段，用户只需修改项目名称即可提交；不复制规则、Tag、全局 Mock 开关或本地响应 | 已实现 |
| R2 | Apifox 在线连接与同步 | 通过项目 ID + Access Token 验证在线连接；发现可用 Tag；预览接口和新增/更新/删除/保留数量；确认后固定替换 Apifox 来源规则，保留 Custom/Imported 规则；可打开接口对应的 Apifox Web 页面 | 已实现 |
| R3 | Token 与 Mock URL | Access Token、Mock Token 随 Profile 写入本地配置并在表单回显；同步生成的 Apifox 目标显式携带 URL 编码的 `apifoxToken`；运行时用当前 Token 覆盖旧参数；日志、诊断、Toast 和错误中不得出现明文 Token | 已实现 |
| R4 | 规则匹配与 CRUD | 按规范化 host、路径前缀、全局开关、Method、优先级和接口开关确定性匹配；支持 `exact`、`template`、`regex`、`contains`；OpenAPI `{param}` 可匹配实际动态路径；任意来源规则可编辑和删除 | 已实现 |
| R5 | 全局/单接口 Mock 控制 | 应用启动安全透传；全局 Mock 关闭时全部透传且不改写单接口状态；开启后仅已启用接口参与匹配；“仅调试当前接口”可临时只保留当前接口生效 | 已实现 |
| R6 | HTTP/HTTPS 代理生命周期 | 活动项目存在时自动监听 loopback 端口；绑定成功后才显示运行；切换项目、改端口或删除活动项目时自动切换；端口冲突和错误明确可见；未命中请求保留必要方法、查询、请求体和业务头并透传 | 已实现 |
| R7 | HTTPS CA 与接入诊断 | 支持生成/读取本地 CA、打开证书、刷新信任状态并显示 DER SHA-256 指纹；私钥权限为 `0600`；接入检查显示代理地址、监听状态和 CA 状态；不自动取得管理员权限或修改系统信任 | 已实现 |
| R8 | 请求记录与诊断 | 通过桌面事件实时记录每个请求；显示来源、目标、规则、阶段、状态、响应码和耗时；已 Mock 且对应规则仍存在时可只读查看该规则信息；支持搜索、状态筛选、清空和固定滚动区域；最多保留 500 条请求记录及 100 条诊断记录；敏感头、Cookie、Body 和 Token 不落盘 | 已实现 |
| R9 | Mock 接口测试与协作操作 | 每条接口支持测试、重试、响应内容搜索/多匹配导航、复制原始接口、跳转 Apifox 设置页；支持单条移动、批量移动和批量删除，操作有确认且跨 Tab 冲突时整批失败不产生部分写入 | 已实现 |
| R10 | 本地 Mock 响应预设 | Profile 可新增、编辑、复制、删除本地响应预设（名称、延时、状态码、UTF-8 响应体）；接口可绑定预设；命中后由本地代理直接返回，不访问 Apifox；测试弹框展示预设结果；未绑定时保持原 Apifox 转发行为 | 已实现（已合并需求） |
| R11 | 真机模拟提示词 | 可勾选接口并生成复制用的真机模拟提示词；提示词只要求替换 URL，并带删除 TODO、禁止提交等约束；不修改小程序代码 | 已实现 |
| R12 | 安全迁移与可安装交付 | 配置带 `schemaVersion`，旧演示数据可迁移为空状态并保留 `.bak`；配置原子写入；完成前端构建、源码约束、Rust 检查/测试和 arm64 `.app/.dmg` 打包；真实微信开发者工具验收仍需人工完成 | 已实现，人工验收依环境执行 |

## 运行规则

- 只有活动 Tab 参与代理匹配，其他 Tab 的同名接口不会重复拦截。
- Tag 只用于同步筛选和接口归类，不作为运行时开关；运行时由全局 Mock 和逐接口开关决定。
- Apifox 当前用户流程为在线模式；模型中保留的 Local 字段仅用于兼容既有配置，不作为当前界面承诺。
- 代理只监听 loopback，不提供透明代理、VPN 或 WebSocket/流式专用 Mock。
- 应用不绕过客户端 certificate pinning；未信任 CA 时不能宣称 HTTPS 可用。

## 非目标与限制

- 不修改微信小程序源代码、构建配置或请求封装。
- 不自动设置 macOS 全局代理，不静默导入或信任 CA。
- 不承诺绕过 certificate pinning。
- 不实现请求体条件匹配、响应脚本执行、WebSocket/流式响应专用 Mock、透明代理或 VPN。
- “微信开发者工具可用”不能仅由本地自动化测试推出，必须使用真实源域名、Apifox 项目和微信开发者工具进行人工验收。
