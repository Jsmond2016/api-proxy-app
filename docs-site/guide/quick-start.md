# 快速流程

1. 创建联调项目，填写名称、源站域名、可选路径前缀和未占用端口。
2. 在 Apifox 面板填写项目 ID 与 Token，验证连接后选择 Tag 并预览同步结果。
3. 确认同步，将需要的接口写入当前项目的 Mock 规则列表。
4. 生成并信任本地 CA。
5. 在微信开发者工具的代理设置中，将 HTTP 和 HTTPS 都设置为 `127.0.0.1:<PORT>`。
6. 开启全局 Mock，并确认目标接口的单条开关已开启。
7. 在小程序中发起请求，在“代理流量”中查看“已 Mock”或“透传”结果。

未命中 host、路径前缀、Method 或规则的请求不会被阻断，会继续转发到原始服务。
