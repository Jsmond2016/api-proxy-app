# 支持配置本地mock响应体 需求文档

## 开发分支

`feature/支持配置本地mock响应体`

## 背景与目标

为微信开发者工具联调提供不依赖上游服务的本地 Mock 响应预设。用户可在 Apifox 按钮左侧管理预设响应，并在接口规则中选择预设；规则命中后由本地代理直接返回配置的状态码、延时和响应体。

## 代码范围（可选）

| 分类 | 内容 |
| --- | --- |
| 路由 | 无（Tauri 桌面应用） |
| 代码文件 | `src/types.ts`、`src/App.tsx`、`src/components/RuleTable.tsx`、`src-tauri/src/model.rs`、`src-tauri/src/commands.rs`、`src-tauri/src/proxy/mod.rs`、绑定文档 |
| 关联接口 | Tauri 本地响应预设与规则 CRUD commands |
| 功能点 | Profile 级本地响应 CRUD、规则引用、HTTP/HTTPS 直接响应 |

## 需求范围

| ID | 需求点 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| R1 | Apifox 按钮左侧提供“新建本地 Mock”入口，弹框内支持新增、编辑、复制和列表展示预设响应 | 可打开管理弹框；新增表单包含响应名字、延时返回（默认 0）、HTTP 状态（默认 200）、响应体；确定后列表出现；编辑原记录不新增；复制生成名称追加 `-copy` 的新记录并可编辑保存 | 已实现 |
| R2 | 接口规则支持启用“使用预设响应体”并选择一个预设 | 编辑接口时可开启开关并选择单选下拉；保存后规则持久化引用；关闭时保持原 Apifox 转发行为 | 已实现 |
| R3 | 命中启用预设的 HTTP/HTTPS 规则时由代理直接返回本地响应 | 请求按既有 host/path/method 规则命中后返回配置状态码、响应体和延时，不访问上游；未命中或未启用仍透传/转发 | 已实现 |

## 非目标

不修改微信小程序代码；不实现请求体条件匹配、响应体脚本执行、WebSocket/流式响应专用 Mock；预设响应仅保存在本地 Profile 配置。

## 注意事项

保持现有 Apifox 规则和配置向后兼容；响应体按 UTF-8 文本处理；延时需限制为非负整数；代理仍仅监听 loopback，HTTPS 仍要求 CA 信任；不得把响应体写入请求日志。
