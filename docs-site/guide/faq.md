# 常见问题

## 没有请求记录

确认活动项目的代理状态为运行中，且微信开发者工具的 HTTP、HTTPS 代理都指向应用展示的本地地址。仅打开网页预览无法监听代理端口。

## HTTPS 请求提示证书错误

重新打开应用生成的 CA 文件，在 macOS 钥匙串中导入并设为始终信任，然后回到应用刷新信任状态。客户端启用了 certificate pinning 时，应用无法代替客户端绕过校验。

## 请求没有被 Mock

依次查看请求记录中的阶段：源站 host、路径前缀、全局开关、Method 和单条规则都必须命中。关闭全局 Mock 时，单条接口开关会被保留，但所有请求仍透传。

## Apifox 返回认证错误

重新填写 Access Token 后验证连接；Mock 服务鉴权失败时，重新填写 Mock Token 并同步规则。不要将 Token 放入日志、截图或公开问题中。
