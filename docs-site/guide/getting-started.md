# 开始使用

## 适用场景

在不修改小程序业务代码、构建配置或请求封装的前提下，对指定接口进行 Mock 联调。每个联调项目独立保存源站范围、监听端口、Apifox 连接、规则和本地响应。

## 前提

- macOS 与微信开发者工具。
- 可访问的 Apifox 在线项目及其项目 ID、Access Token；需要鉴权时另备 Mock Token。
- 一个待代理的源站域名，例如 `api.example.test`。

不要把 Token、真实业务域名或请求内容粘贴进公开文档、截图或问题反馈中。

## 安全边界

应用启动后默认全量透传。只有用户信任本地 CA、在微信开发者工具显式设置 HTTP/HTTPS 代理，并开启全局 Mock 后，符合规则的请求才会被改写。

应用不自动获取管理员权限，不能绕过客户端的 certificate pinning。
