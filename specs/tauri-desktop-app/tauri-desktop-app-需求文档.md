# Tauri Desktop App 需求文档

## 开发分支
`feature/tauri-desktop-app`

## 背景与目标

将现有 API Proxy Tool 的 Apifox Mock 联调能力迁移为 macOS 桌面应用，服务微信小程序开发者。在不修改小程序业务请求代码的前提下，用户可以通过本地代理将指定真实 API 转发至 Apifox Mock，并在桌面端管理规则和请求记录。

## 需求范围

| ID | 需求点 | 验收标准 | 状态 |
| --- | ------ | -------- | ---- |
| R1 | macOS 桌面应用基础工程 | Tauri 原生窗口可显示代理工作台 | 已验证 |
| R2 | 联调项目档案 | 可创建、编辑、删除、切换独立项目档案并在重启后保存 | 部分实现 |
| R3 | Apifox 接口同步 | 支持本地 OpenAPI 导出链接、在线项目导出和 Tag 选择 | 部分实现 |
| R4 | Mock 规则管理 | 可显示规则并单独启停；后续补齐创建、编辑和导入 | 部分实现 |
| R5 | 本地代理生命周期 | 可启动、停止并查看代理端口状态；未命中请求保持透传 | 已实现，待端到端验证 |
| R6 | HTTPS 无侵入联调 | 支持 HTTP/HTTPS CONNECT、根证书生成、安装与信任状态检查 | 部分实现 |
| R7 | 微信开发者工具接入 | 展示本地代理地址、状态和接入说明，无需改业务代码 | 部分实现 |
| R8 | 请求匹配与转发 | 按 method、exact、contains、regex 匹配，保留请求语义并转发至 Mock | 已实现，待端到端验证 |
| R9 | 请求日志 | 显示实时请求、命中规则、目标、状态和失败原因，支持筛选 | 部分实现 |
| R10 | 本地数据与凭据安全 | 配置持久化；Token 不出现在日志/导出中并保存于 macOS Keychain | 待开发 |
| R11 | 配置迁移与备份 | 兼容参考项目模块/接口 JSON 的导入，导出时移除敏感凭据 | 待开发 |
| R12 | 代码规模与表达式约束 | `.js`、`.ts`、`.tsx` 单文件不超过 500 行；禁止三元表达式；样式、配置文件不受行数限制 | 已验证 |

## 非目标

- 第一阶段不提供浏览器扩展间消息、权限点提取、迭代归档和团队云同步。
- 第一阶段不实现自定义 JSON 响应编辑。
- 不修改微信小程序源码、构建配置或请求封装。
- 不自动修改 macOS 系统代理设置。
